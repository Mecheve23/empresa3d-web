#  Plataforma Web Integral - Diseña y Fabrica 3D

Plataforma web dinámica diseñada y desarrollada para automatizar la captación comercial, catálogo de productos y gestión de cotizaciones personalizadas de servicios de impresión 3D y prototipado industrial.

##  Características Principales

* **Módulo de Cotizaciones a Medida:** Permite a los clientes adjuntar especificaciones y modelos técnicos (formatos `.STL`, `.STEP`, `.PDF`).
* **Catálogo Comercial y Carrito:** Visualización de productos en stock con carrito de compras y canalización directa de pedidos vía WhatsApp.
* **Panel de Administración Autogestionable:** Módulo protegido para gestionar productos, pedidos, colaboradores y solicitudes de cotización en tiempo real.
* **Arquitectura Dinámica:** Conexión persistente mediante MySQL con consultas optimizadas.

##  Tecnologías Empleadas

* **Backend:** PHP nativo
* **Base de Datos:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Entorno de Desarrollo:** XAMPP (Apache, phpMyAdmin)
